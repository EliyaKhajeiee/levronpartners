## Key results

- Weekly quoting time dropped from **10–15 hrs to 3–5 hrs**
- **~40 hours a month** recovered and redirected to running the business
- A single voice command now generates a fully formatted quote
- Manufacturer warranty terms and install specs applied automatically
- No more retyping or copy-pasting the same line items job after job

## The problem

Kung Fu Air Service was spending 10–15 hours a week on quoting. Every job required the same repetitive line items — removing the old unit, applying manufacturer warranty terms, documenting flare connection specs — typed or copy-pasted by hand, every single time.

None of it was hard work. It was just the same handful of details, re-entered over and over, for every quote that went out the door — the kind of hours that quietly eat an HVAC owner's week without ever showing up as a line item anywhere.

## What we found

The pattern was clear: quoting followed a small, predictable set of rules. The unit, the install specs, and the warranty terms changed from job to job, but the structure of every quote — and most of its language — stayed the same.

That's exactly the kind of repetitive, rule-based work that shouldn't require someone typing it out by hand each time.

## What we built

A voice-driven quoting tool. Chris Barr, the owner, gives a simple voice command — for example, *"install a 12,000 BTU Fujitsu, new piping, new line covers, new condenser pads"* — and the tool generates a fully formatted quote automatically, applying manufacturer warranty terms, standard install warranties, and installation specs without any manual entry.

The tool handles:

- Voice-to-quote generation from a single spoken command
- Automatic application of manufacturer warranty terms
- Standard install warranty language applied by default
- Installation and flare connection specs documented automatically
- Fully formatted, ready-to-send quotes — no retyping or copy-pasting

## The result

| Metric | Before | After |
|---|---|---|
| Weekly quoting time | 10–15 hrs | 3–5 hrs |
| Quote line items | Typed/copy-pasted | Voice-generated |
| Warranty terms | Manual entry | Applied automatically |

**~40 hours recovered every month** — worth roughly **$39,000/year** at a conservative $75/hr operator rate.

> "This is exactly what AI was made for."
> — **Chris Barr**, Owner, Kung Fu Air Service

## What this means if you run a mechanical or trade business

If your estimators are re-typing the same warranty language, install specs, and line items on every quote, that time is recoverable — usually faster than a new hire would be trained. The workflow doesn't need to be replaced; it needs the repetitive 80% taken off someone's plate so the judgment calls (pricing, scope, customer fit) are the only thing left for a person to do.
